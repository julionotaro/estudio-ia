# Operational Workflow v0.3 - Plantilla de Automatizacion de Oficina

## Objetivo

Plantilla base para proyectos de automatizacion documental u operativa.

## Pipeline base

Trigger
-> Extraction Agent
-> Filtro Codigo Rigido
-> QA and Compliance Agent
-> Decision Engine
-> Action Execution
-> Communications Agent

## Uso previsto

Esta plantilla se usa cuando el proyecto incluye:
- documentos
- emails
- procesos repetitivos
- validaciones exactas
- integracion con sistemas externos
- comunicacion automatica con clientes
- checkpoints humanos

## Regla central

La IA puede interpretar, resumir y asistir.
Las decisiones exactas o reguladas deben pasar por reglas rigidas, validaciones o checkpoints humanos.
