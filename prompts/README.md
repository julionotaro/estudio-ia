# Prompts canonicos - Estudio IA

Este paquete contiene los 16 prompts originales organizados por fase.

- design-phase: direccion, analisis, arquitectura, tech lead, UX y project manager.
- builder-phase: construccion backend, base de datos, integraciones, UI y frontend.
- support-phase: QA, deploy y documentacion.

No contiene exports YAML de Dify. Esos deben exportarse manualmente desde Dify Cloud.
