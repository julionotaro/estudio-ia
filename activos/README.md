# Activos reutilizables

Componentes, guias y patrones que sirven a cualquier proyecto cliente del estudio, independientes de un cliente concreto.

## Contenido

- `rpa-playwright/` — Automatizacion de plataformas web sin API (guia + demo funcional).

## Criterio

Un activo vive aqui si responde si a: *esto me serviria tal cual en el proximo cliente?* Lo que solo tiene sentido para un cliente concreto va en su repo, no aqui.
